# Turtle Graph Plotter

My lightweight Python script that uses the turtle module wich is natively indtalled with python to plot mathamatical functions. The projectthe (x,y) values visually while computing values and tracking the gradient  directly inside the terminal .

## Features

* Simple lightwhight code to map out mathamatical fucntions
* Has dedicated code for trigenometric fucntions
* In terminal is displays the current x,y values and gradient .

## Installation

To use this code you must have python version 3 or higher .To install python you can visit
*[https://www.python.org/downloads/](url)

#### To install it Via console you may run the command suited to you operating system
* **Mac OS:**
```bash
brew update
brew install python@3.14
```

* **Linux:**
```bash
sudo apt update
sudo apt install python3.14
```

* **Windows:**
```powershell
winget install Python.Python.3.14
```
